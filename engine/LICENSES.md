# Third-party assets shipped by the engine (R-ASSET-12)

Only the files a site's locales and pages need are copied into `dist/<site>/assets/`. Per-site assets supplied by a brief are listed in that site's `DECISIONS.md`.

| Asset | Used for | Package | Licence |
|---|---|---|---|
| Lucide icons | the per-page SVG sprite (`engine/icons.json` allow-list) | `lucide-static` 1.59 | ISC, https://github.com/lucide-icons/lucide/blob/main/LICENSE |
| Inter | brand font `inter` (default) | `@fontsource-variable/inter` 5.3 | SIL Open Font License 1.1, https://github.com/rsms/inter/blob/master/LICENSE.txt |
| Noto Sans Arabic | Arabic script face, added for `ar`, `fa` and `ur` locales; subset at build time to its core blocks and weights 400–700 (D28) | `@fontsource-variable/noto-sans-arabic` 5.3 | SIL Open Font License 1.1, https://github.com/notofonts/arabic/blob/main/OFL.txt |
| Figtree | brand font `figtree` (install `@fontsource-variable/figtree` when a brief picks it) | `@fontsource-variable/figtree` | SIL Open Font License 1.1, https://github.com/erikdkennedy/figtree/blob/master/OFL.txt |
| IBM Plex Sans | brand font `ibm-plex-sans` (install when picked) | `@fontsource-variable/ibm-plex-sans` | SIL Open Font License 1.1, https://github.com/IBM/plex/blob/master/LICENSE.txt |
| Source Sans 3 | brand font `source-sans-3` (install when picked) | `@fontsource-variable/source-sans-3` | SIL Open Font License 1.1, https://github.com/adobe-fonts/source-sans/blob/release/LICENSE.md |
| Noto Sans | brand font `noto-sans` (install when picked) | `@fontsource-variable/noto-sans` | SIL Open Font License 1.1, https://github.com/notofonts/latin-greek-cyrillic/blob/main/OFL.txt |
| FFmpeg (static build) | encodes the generated sample clip at build time (R-ASSET-13); the binary runs on the build machine only and nothing of it ships in `dist/` | `ffmpeg-static` 5.3 (downloads the binary on `npm install`) | GPL-3.0-or-later for the binary, https://github.com/eugeneware/ffmpeg-static/blob/master/LICENSE; the clips it writes are the site's own work |

Fonts are served self-hosted from `/assets/fonts/` with the OFL's reserved-font-name terms respected (family names are the fontsource names). Placeholder images, social images, favicons and customer wordmarks are generated by the build from the brand hue and carry no third-party rights.
