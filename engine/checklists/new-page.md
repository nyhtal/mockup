# New page checklist

Use this for every page added to a site, whether a singular page (one front-matter file per locale) or a new entity detail page (one recipe in `pages.json` per locale and one entity per locale).

## Procedure

1. **Find the page type's row** in `engine/bylaws/09-pages.md`: URL, title pattern, required and optional sections in order, schema contract. If the type is not in the inventory, it is a bylaw change (R-PREC-03), not a page.
2. **Singular page**: add `content/<locale>/<path>.md` in every locale with `layout`, `pageType`, `conversion`, `title`, `eyebrow`, `lede`, `description` and `sections` (site section ids from `pages.json`, catalog sample ids, or inline objects). Non-home pages get their page-header from the title automatically.
3. **Entity page**: add the entity to `data/<locale>/entities.json` in every locale with the same slug, and if the kind is new, a `detail` recipe in `pages.json` (`each`, `layout`, `sections` with `{e.field}` placeholders, `from: "e.<list>"`). The engine generates the URL from the kind's index path.
4. **Forms**: a page with a form names its thank-you page in `pages.json` `thankYou` keyed by the form page's path, and the form's `action` points at it.
5. **Copy**: title ≤ 60 characters, description 120–155 characters, lede ≤ 35 words, no forbidden words, sentence case, verb-first button labels, in every locale.
6. **Build and gate** with `--skip lighthouse`; the consistency gate reports title and description lengths, the schema gate the contract, the links gate every href.
7. **Open the page at 320 px and 1024 px** in every locale: no horizontal scrolling, no wrapped CTA, no truncated label.

## Learned on the reference site

- Breadcrumbs skip URL segments that have no page of their own (`/blog/tag/`), so an index page is optional but a crumb never points at a 404.
- A description that starts with a single word and a colon ("Northwind-Preise: …") parses as a URL with a scheme and fails the links gate; reword it.
- The budget counts every font whose `unicode-range` matches text on the page: one Arabic word in a Latin page pulls the Arabic face unless it is set in `font-system`.

## Rules this checklist verifies

Generated by `npm run checklists` from every rule whose `Gate:` line names `checklists/new-page.md`; edit the bylaws or the preamble in `_preambles/`, not this list. Tick each item or record the override in the site's `DECISIONS.md` (R-PREC-02; tier-1 rules cannot be overridden).

### 00 Precedence, overrides and the shape of a rule

- [ ] **R-PREC-06** Catalog verbatim — Pages are composed from catalog sections and components without editing their markup or classes. A new need is met by adding a variant to the catalog, never by improvising on a page.

### 01 HTML

- [ ] **R-HTML-14** Dates and addresses — Dates are `<time datetime="YYYY-MM-DD">` with locale-formatted text. Postal contact details are in `<address>`; `address` is never used for author bylines.

### 04 Typography

- [ ] **R-TYPO-07** Length limits — h1 ≤ 60 characters, h2 ≤ 80, eyebrow ≤ 30, button label ≤ 25, nav item ≤ 18, card title ≤ 70, lede ≤ 35 words. Limits apply to every locale; characters are display widths (R-HTML-03) and in Japanese two characters count as a word.
- [ ] **R-TYPO-11** Capitalisation — Sentence case everywhere: headings, buttons, nav, labels. `uppercase` is allowed only on eyebrows and badges, with `tracking-wide`.

### 06 Motion

- [ ] **R-MOT-11** No motion on load above the fold — Nothing above the fold animates on first paint: the hero, header and first section render in their final state; the hero's proof strip and highlight card do not count. `enhance.js` marks every entrance whose top is already above 88 % of the window as revealed before it sets `data-entrances`, the flag `pending:` waits for, so content visible at load never fades in. Scroll-linked movement that is at identity while `scrollY` is 0 (the depth layers of R-MOT-15 on the hero media and glows) is not an entrance and is allowed; the hero's text column and highlight card never move.

### 08 Sections

- [ ] **R-SEC-02** One h2 per section — Each section has exactly one `h2`; items inside use `h3`. Sections without a visible title (logo cloud, CTA band) carry `aria-label` instead of an empty heading.
- [ ] **R-SEC-03** Content limits — Feature grid 3–6 items; alternating feature rows 2–4; feature bento 3–6 (the first is the lead); feature index 3–6; feature spotlight 2–4 beside one picture; feature disclosures 2–5; stats 3–4; logo cloud 5–8; testimonials 1–3 (carousel up to 6); FAQ 4–10; steps 3–5; timeline 4–8; team 4–12; pricing 2–4 tiers; case-study cards 3 or 6; related items 3; office cards 2–6; job list 1–20 with pagination beyond.
- [ ] **R-SEC-04** Word limits — Lede ≤ 35 words; card body ≤ 40 words; testimonial quote ≤ 50 words; stat label ≤ 4 words; feature title ≤ 6 words (index, spotlight and disclosure titles ≤ 8); feature-index text ≤ 45 words, spotlight point ≤ 30, disclosure text ≤ 50, the bento lead ≤ 50; step description ≤ 25 words; CTA band copy ≤ 20 words.
- [ ] **R-SEC-05** Calls to action — A page has one primary CTA (the header button) plus at most one CTA band; sections otherwise end in a secondary or link-style CTA. Two primary buttons never sit next to each other.
- [ ] **R-SEC-06** Alternating surfaces — Sections alternate `bg-surface` and `bg-surface-alt` starting with `bg-surface` after the hero; a media-background section (hero, CTA band) resets the alternation.
- [ ] **R-SEC-07** Hero — Variants: `centered`, `split` (text + media), `video` (facade), `form` (text + short form), `stats` (text + 3 stats), and three on the art library (R-ASSET-05): `backdrop` (a dark-tone piece fills the section, or with `inset` a `rounded-3xl` frame inside the container, or with `light` a light-tone piece behind the page's ink and the light scrim, in the light colour scheme whatever the theme; the text sits in inverse ink over the piece's quiet start side behind the art scrim of R-COL-09, mirrored in RTL; at least `lg:min-h-144`, inset `lg:min-h-160`; no highlight card), `panel` (a dark-tone piece fills the section and the text sits on an opaque `bg-surface-raised` panel across seven columns, so it never touches the picture) `cinema` (the sample clip of R-ASSET-13 fills the section behind the art scrim, showing its poster, with the text in inverse ink and a round play button; pressing it plays the clip in place with the native controls while the text and scrim step aside, and they return when it ends; nothing plays on its own, D52; without the script the native player shows its controls) and `editorial` (eyebrow, an h1 at `text-5xl md:text-6xl xl:text-7xl` in `font-medium` across ten columns, the lede and the actions on one row under it, then a 21:9 panorama in a `rounded-2xl` frame). The hero contains the page's `h1`, a lede, one primary and one secondary button, and the LCP image (`fetchpriority="high"`); split, video and form variants sit on twelve columns: text seven and media five at `lg`, six and six at `xl` (a German compound at the display size needs the measure). It may add a proof strip (≤ 3 figures with labels under the buttons) and, with media, a highlight card (icon, figure, label) over the media's top-end corner. It never animates on load (R-MOT-11).
- [ ] **R-SEC-08** Page header — Non-home pages that are not landing pages start with the `page-header` section (breadcrumbs, eyebrow, `h1`, lede) instead of a hero, chosen in the page's front matter as `pageHeader: { variant, image }`: `plain` (the default), `brand` (a solid band in the brand blue, R-SEC-13, no image), `banner` (a dark-tone art piece behind the whole header with the art scrim, breadcrumbs and text in inverse ink, `py-16 md:py-24`), `band` (the plain header, then a `rounded-2xl` 21:9 art band `mt-12` under the lede) or `split` (text in seven columns, a 4:3 art frame in five, stacked below `lg`); a variant without an image is `plain`. A page whose first section is `search-box` (the search and help pages) opens on that section's header form instead: breadcrumbs, the page's eyebrow, h1 and lede, the search field showing the query of the page's results and the popular searches, on the alternate surface, so the title and lede appear once. Followed by a plain section on the page surface, a plain or split header joins that section as the opening group of R-LAY-02; a banner or band header keeps its padding.
- [ ] **R-SEC-09** Section order per page type — Required and optional sections and their order for each page type are listed in bylaw 09's inventory table; a page uses that order and may omit optional sections but never reorders required ones.
- [ ] **R-SEC-11** Empty and error sections — List sections (jobs, search results, filtered resources) render the `empty-state` component when they have no items, with a next action; they never render an empty grid.
- [ ] **R-SEC-12** Section data contract — Each section's include takes one object whose keys are documented in its anatomy block (`title`, `eyebrow`, `lede`, `items[]`, `cta`); pages pass data, never markup.
- [ ] **R-SEC-13** Brand version — Every section can take its brand version, the contrast that stands in for text over a dark picture: `tone: "brand"` paints it in the stats band's blue (`brand-700`) as a full-width bar, and with `frame: "contained"` as a `rounded-3xl` panel inside the container on the page surface. The `tone-brand` utility re-points the role colours inside it (ink and muted ink to the inverse, lines to translucent inverse, raised cards a step lighter, brand text to `accent-200`, focus to the inverse), so components need no variant of their own; shell sections get it from the shell, the classic heroes from `s.tone`, the page header as its `brand` variant. A brand bar never joins a page header and restarts the surface alternation after it; primary buttons stay off it (its CTA is the secondary button).

### 09 Pages

- [ ] **R-PAGE-02** URL policy — URLs are `/<locale>/<slug>/` with lower-case hyphenated slugs, trailing slash, no file extension, at most three segments below the locale. Detail pages live under their index (`/en/services/<slug>/`). Slugs are translated per locale via `site.json` `slugs` when the brief asks; otherwise the default-locale slug is reused.
- [ ] **R-PAGE-03** One primary conversion per page — Each page declares `conversion` in front matter (demo, contact, download, apply, subscribe, none); the header CTA and the CTA band both point at it.
- [ ] **R-PAGE-04** Meta contract — Each page type has a title pattern and a description pattern (table below); breadcrumbs reflect the URL path; the OG image is the generated social image for that page (bylaw 17).
- [ ] **R-PAGE-10** Thank-you pages — Every form has its own thank-you page (`/<locale>/<form-slug>/thank-you/`) with `noindex`, a confirmation of what happened and one next step.
- [ ] **R-PAGE-11** Pagination and archives — Index pages paginate at 12 items with `rel="prev"`/`rel="next"` links in the body, page numbers in the URL (`/en/blog/page/2/`), and `noindex` on tag archives.

### 10 Content

- [ ] **R-CONT-02** Sentence case — Headings, buttons, nav items, labels and table headers use sentence case. Only proper nouns and product names are capitalised.
- [ ] **R-CONT-03** Punctuation — Oxford comma; no exclamation marks; no ampersands outside names; en dash for ranges with no spaces (9–17); no trailing periods on headings, labels, list items under seven words, or buttons.
- [ ] **R-CONT-04** Numbers — Zero to nine as words, 10 and above as numerals, except in stats, tables, prices, dates and units which are always numerals. Percentages use `%` with no space; units follow locale rules in bylaw 11.
- [ ] **R-CONT-05** Button labels — Buttons start with a verb from: Get, Start, Book, Talk, Request, Download, Apply, See, Read, Explore, Subscribe, Send, Search, Compare, Watch, Open, Close, Cancel, Save, Continue, Back. Labels are 1–4 words and never "Click here", "Submit", "Learn more" or "More".
- [ ] **R-CONT-06** Link text — Link text describes the destination ("See pricing", "Read the Northwind case study") and is unique within a page. "Here", "this", "read more" and bare URLs are not link text.
- [ ] **R-CONT-07** Forbidden words — These words do not appear: leverage, synergy, cutting-edge, best-in-class, world-class, seamless, robust, utilize, solutions (as a noun on its own), innovative, disrupt, lorem, ipsum, "click here", "please note", very, really, just.
- [ ] **R-CONT-09** Reading level — Body copy targets a grade-8 reading level: short sentences, common words, one idea per sentence, no nested clauses. *(SHOULD)*
- [ ] **R-CONT-12** Terminology glossary — `sites/<name>/glossary.json` lists the product and industry terms with their exact spelling and capitalisation per locale; copy uses only those forms (for example "control software", never "control-software" or "Control Software" mid-sentence).
- [ ] **R-CONT-14** Dates, times, currency — Dates are written out per locale (bylaw 11), times use the 24-hour clock with the time zone named, currencies show the symbol and ISO code once per page (€12,000 (EUR)).

### 12 SEO and metadata

- [ ] **R-SEO-02** Canonical — `<link rel="canonical">` is the page's own absolute URL on `site.url`, trailing slash included; paginated pages are self-canonical.
- [ ] **R-SEO-09** Headings carry the keywords — The `h1` contains the page's main noun; the first paragraph repeats it naturally; `h2`s name the sections in plain words rather than slogans. *(SHOULD)*
- [ ] **R-SEO-14** Language and region signals agree — `html lang`, `og:locale`, `inLanguage` in JSON-LD, the locale folder and the hreflang entry for the page all name the same locale.

### 13 Structured data

- [ ] **R-SCH-06** Visible content only — Every value in the graph is visible on the page (name, dates, prices, authors, questions and answers); nothing is added for the markup's sake.
- [ ] **R-SCH-08** No fabricated signals — No `AggregateRating`, `Review`, `award`, or `sameAs` to real profiles unless the brief supplies real data; `FAQPage` is allowed on the FAQ page for validity but no rich result is expected; `HowTo` is not used.
- [ ] **R-SCH-09** LocalBusiness only when local — An office is a `Place`; it becomes `LocalBusiness` only when the brief says customers visit it (showroom, clinic, branch). The organization is never typed `LocalBusiness`.
- [ ] **R-SCH-10** Dates and languages — Dates are ISO 8601 (`2026-10-17` or `2026-10-17T09:00:00+01:00`); `inLanguage` is the page's BCP 47 tag.
- [ ] **R-SCH-14** Social and schema agree — `name`, `description`, `image` and `inLanguage` in the graph equal the title, meta description, OG image and `lang` of the page.

### 15 Performance

- [ ] **R-PERF-08** No motion cost at load — R-MOT-11: nothing above the fold animates at load; reveal animations below the fold use the compositor only.
- [ ] **R-PERF-12** DOM size — A page has at most 800 elements and a depth of at most 12; long lists paginate (R-PAGE-11).
- [ ] **R-PERF-13** Icons inline, once — The SVG sprite is inlined once per page before the footer and contains only icons used on that page (built per page by the icon tool).
- [ ] **R-PERF-17** Video — A page's video elements use `preload="none"` and a poster, so nothing of the clip loads before play; each clip is ≤ 1.5 MB per format at 1280×720 and ≤ 10 seconds for a sample; the budget gate counts the poster, not the clip.

### 16 Forms

- [ ] **R-FORM-12** Success page — The thank-you page confirms what happened ("We received your request"), says what happens next and when, and offers one next step; it is `noindex`.

### 17 Assets

- [ ] **R-ASSET-13** Sample video — `engine/tools/build-video.js` generates every clip a page declares (`{ "slug", "title", "duration" }`): frames of the art library's system in motion (Offset Planes, DESIGN §5: flat planes in five steps of the brand's dark ramp gliding along their axes, the start 40 % empty, the poster the composition at rest, looping), encoded with `ffmpeg-static` to `/assets/video/<slug>.mp4` (H.264, yuv420p) and `<slug>.webm` (VP9), with `<slug>-poster.webp` from the first frame and one `<slug>-<lang>.vtt` captions file per page language (its cue is `ui.videoCaption`); builds are seeded by slug so rebuilds are identical and skipped when the files exist.
