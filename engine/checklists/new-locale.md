# New locale checklist

Use this when a site adds a language. The reference site added German (text expansion) and Arabic (right-to-left, its own script) in one phase; both are worked examples under `sites/reference/`.

## Procedure

1. **Engine strings**: copy `engine/i18n/_template.json` to `engine/i18n/<locale>.json` and translate every key, keeping placeholders (`{n}`, `{count}`, `{query}`, `{provider}`, `{label}`) and giving plural strings all five CLDR forms. Add the locale to `OG_LOCALES` and `FORMAT_LOCALES` in `eleventy.config.js` if its tag needs a region.
2. **Site strings**: `sites/<name>/i18n/<locale>.json` with the same keys as the default locale's overlay (nav, footer, `site.tagline`, site map groups).
3. **Site config**: add the locale to `site.json` `locales`, and to `rtl` when it is right-to-left; `numberingSystem` only if the brief asks for native digits.
4. **Content**: `data/<locale>/entities.json` and `pages.json` with every slug and section id of the default locale (a missing site section fails the build; a missing page fails the coverage check), and `content/<locale>/*.md` for every singular page. Locale-specific legal pages (imprint for `de`/`at`) exist only where required.
5. **Lengths in the new language**: descriptions 120–155 characters, titles ≤ 60, button labels ≤ 25, nav items ≤ 18; the consistency gate measures the first two.
6. **Script coverage**: if the brand font does not cover the script, `build-fonts.js` adds the script face, subsets it, puts it in the stack and preloads it on that locale's pages. Check the built CSS `--font-sans` and the `<link rel="preload">` on a page of the locale.
7. **Build and gate** with `--skip lighthouse`; `i18n/keys` and `i18n/lang-attr` must be clean.
8. **Open the locale in the browser pane**: one page per template at 320 px, 1024 px and 1280 px. Check the header, drawer, breadcrumbs, cards, forms, footer and locale switcher. For RTL: the wordmark reads left to right, chevrons and arrows mirror, the drawer opens from the end edge, numbers and dates are formatted (Latin digits unless opted in).
9. **Native-speaker proofread** of the strings and the content before delivery; record who read it in the site's `DECISIONS.md`.

## Learned on the reference site

- German compounds in headings ("Stillstandskostenrechner") overflow 320 px unless the body hyphenates (`hyphens-auto` for `de`) and wraps (`wrap-break-word`).
- The header holds four nav groups, the switcher, search and the CTA only from `xl`; between `lg` and `xl` the switcher is icon-only and the wordmark one step smaller.
- Arabic plurals: "1 دقائق قراءة" is wrong; `t(key, n)` with the five forms fixes it.

## Rules this checklist verifies

Generated by `npm run checklists` from every rule whose `Gate:` line names `checklists/new-locale.md`; edit the bylaws or the preamble in `_preambles/`, not this list. Tick each item or record the override in the site's `DECISIONS.md` (R-PREC-02; tier-1 rules cannot be overridden).

### 03 Layout

- [ ] **R-LAY-08** Long content and overflow — Text containers use `break-words`; German pages set `hyphens-auto` on prose; tables wrap in `overflow-x-auto` with a visible scrollbar; cards clamp titles to `line-clamp-2` and bodies to `line-clamp-3`.
- [ ] **R-LAY-09** Text expansion allowance — Any component with fixed-width text (buttons, tabs, nav items, badges) is designed to hold 135 % of the English length without truncation; nav collapses to the drawer at `lg` rather than `md` when a locale exceeds it.

### 04 Typography

- [ ] **R-TYPO-05** Line height — Headings use the scale's paired leading (`tracking-tight`, no override); body uses `leading-relaxed`; Arabic pages use `leading-loose` on prose and `leading-snug` on headings.
- [ ] **R-TYPO-12** Glyph coverage — A locale whose script the brief's font does not cover gets its script font added to `font-sans` for that locale's pages only; text is never rendered in images.

### 10 Content

- [ ] **R-CONT-13** Lengths from the sections bylaw — Word and character limits in R-TYPO-07 and R-SEC-04 apply to every locale's copy, not only English.

### 11 Internationalisation

- [ ] **R-I18N-03** Direction — `<html dir>` is `rtl` for locales listed in `site.json` `rtl` (default `ar`, `he`, `fa`, `ur`) and `ltr` otherwise. Layout uses logical properties (R-LAY-04); only directional icons use the `rtl:` variant.
- [ ] **R-I18N-06** No string assembly — Strings are never concatenated from fragments or built with placeholders that change word order; each sentence is one key or one content field. Plural forms are separate keys (`jobs.count.one`, `jobs.count.other`) chosen at build time.
- [ ] **R-I18N-07** Formatting at build time — Dates, numbers, currencies and units are formatted at build time with `Intl` for the page's locale (`en` 17 October 2026, `de` 17. Oktober 2026, `ar` 17 أكتوبر 2026; digits are Latin for every locale unless `site.json` `numberingSystem` opts a locale into its native digits, e.g. `arab`). No formatting in the browser.
- [ ] **R-I18N-08** Locale switcher — The switcher is a popover listing every locale by its native name (`Deutsch`, `العربية`) with `lang` and `hreflang` on each link, never flags, and links to the same page in the other locale.
- [ ] **R-I18N-10** Text expansion — Layouts and limits assume 135 % of the English length (R-LAY-09, R-CONT-13); a locale that still overflows is fixed in the catalog, not by shortening the translation.
- [ ] **R-I18N-11** Fonts per script — Each locale's script has a font in the approved list (R-TYPO-01, R-TYPO-12); the build ships only the subsets its locales need and preloads only the page's primary script. The locale switcher's native language names are set in the system font (`font-system`) so a page never downloads another script's face for one word.
- [ ] **R-I18N-13** Region-specific pages — Pages required by law in some regions (imprint for `de`/`at`, UK modern slavery statement) exist in those locales and are absent elsewhere; the inventory marks them "locale-specific" and the coverage check exempts them via `site.json` `localeOnly`.
- [ ] **R-I18N-14** Addresses, phones, names — Postal addresses follow the office country's format; phone numbers are in international format (`+49 30 1234567`); personal names are not split into first/last fields in forms (one "Full name" field).
- [ ] **R-I18N-16** Images and culture — Generated placeholder imagery is abstract so no locale receives culturally specific scenes; when a brief supplies real imagery, each locale may override it per page. *(SHOULD)*

### 14 Accessibility

- [ ] **R-A11Y-13** Language of parts — Any inline text in another language (a product name is not; a quoted sentence is) carries `lang`.
