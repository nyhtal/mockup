# To do: HTML element coverage, link types, smooth disclosures, theme switch, gallery, filters, paging, common pages

Requested 2026-10-19 by the owner: review how the site uses HTML elements, make sure every HTML element appears somewhere on the site, add in-page links and every link type (tel and the rest), a photo gallery, popups, search filters, paging, a light/dark switch, smooth open/close everywhere, and review for other common pages and sections. Work goes one item at a time; each item is built, checked (build tests, the sampled gate, a browser look) and committed on its own, so a partial run leaves only finished items behind.

## Inventory before the work (288 pages)

- **Elements used: 65 of 112.** Never used: `base style article h5 h6 hgroup menu em small s cite q dfn abbr ruby rt rp data var samp sub sup i b u mark bdi bdo wbr ins del iframe embed object audio map area colgroup col tfoot datalist optgroup output meter noscript slot canvas`. Used only in the style guide: `hr pre strong code kbd progress fieldset legend dialog template`.
- **Link targets:** site paths, `#fragment` (mostly the skip link and back to top), `tel:` 55, `mailto:` 57. No `download`, no `sms:`, no `geo:`, no calendar files, no `rel` values beyond `noopener`, external links only in the style guide.
- **Features:** filter bar only on careers; pagination only in the style guide; image gallery on the culture page without a popup; dialogs only in the style guide; `<details>` open and close without animation; dark mode follows the system with no switch (D7).
- **Security headers:** `script-src 'self'`, `style-src 'self'`, `frame-src 'none'`, `object-src 'none'`, `frame-ancestors 'none'`.
- **Common pages:** the inventory of bylaw 09 already covers home, about, team, people, history, values, locations, offices, services, products, industries, pricing, partners, customers, case studies, resources, blog, posts, tags, authors, downloads, events, FAQ, glossary, help, docs, news, press releases, media kit, careers, jobs, culture, sustainability, trust, contact, demo, newsletter, preferences, unsubscribe, landing page, thank-you, search, site map, legal, error pages. Commonly found elsewhere and missing here: a **changelog / what's new** page, a **podcast or webinar** episode page, an **events calendar file** ("add to calendar"), and **photo galleries** on office pages. A customer sign-in page was considered and left out: a password field submitted by a static mockup would teach the wrong pattern.

## The list

Check that popovers, the drawer and dialogs animate on close as well as open. Bylaw: R-MOT-01 gains a user-initiated disclosure exception for height; R-MOT-06 names the disclosure pattern.
