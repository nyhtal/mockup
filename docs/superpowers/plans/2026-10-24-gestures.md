# Gestures Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Three generic once-per-arrival motion utilities (`gesture-nudge`, `gesture-glow` / `gesture-glow-repeat`, `gesture-trace`), used first on the closing CTA panel and the timeline.

**Architecture:** Each gesture is a Tailwind `@utility` in `engine/theme/app.css` whose animation runs only inside a new `arrived` custom variant (screen, motion allowed, inside an element the existing entrance script marked `data-revealed`). Templates opt in by writing the class, gated by two new flair booleans. No script changes.

**Tech Stack:** Tailwind CSS v4 (`@utility`, `@custom-variant`, `@theme`), Nunjucks templates (Eleventy), Node's built-in test runner.

**Spec:** `docs/superpowers/specs/2026-10-24-gestures-design.md`

## Global Constraints

- Animate only `translate`, `scale` and `opacity` (R-MOT-01).
- Nothing plays under reduced motion, in print, or without the script; `calm` writes no gesture class; only `expressive` writes `gesture-glow-repeat`.
- Each gesture plays once; the glow's pulse runs exactly 3 iterations of 24 s.
- Delays: glow 800 ms after reveal; nudge 1 200 ms (after the glow); trace 2 000 ms (after a 1 200 ms line draw).
- No gesture in the hero. `enhance.js` does not change.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. RTL: the arrow nudges toward the reading direction (left in Arabic) although the icon is mirrored with `scale` → the CSS test asserts `--g-dir: -1` under `:dir(rtl)`; the browser check covers `ar`.
2. Hover after the nudge: the keyframe must not stick and freeze the hover nudge → fill mode `none` asserted in the CSS test.
3. A section in view at load (short pages) plays its gesture about a second after load, never at first paint → covered by the `arrived` variant needing `data-revealed`; checked in the browser.
4. Calm sites keep the new glow layer static → the flair test plus a build assertion that the glow span exists without a gesture class when `gesture` is off.
5. A typo such as `gesture-nod` or a gesture placed in the hero → the consistency gate's motion-vocabulary check flags it (Task 4).
